# Code Hub (MAUI) - Snippet Manager

Code Hub е мобилно приложение, разработено с **.NET MAUI (.NET 8)**, предназначено за разработчици, които искат бързо да създават, съхраняват и анализират кодови фрагменти (снипети) в движение.


## Основни характеристики
* **Локално съхранение:** Използва **SQLite** за надеждно и бързо запазване на данни на устройството.
* **AI Асистент:** Интегриран AI (чрез API) за генериране на код по описание и обяснение на сложни логически фрагменти.
* **Синтактично оцветяване:** Визуализация на кода в реално време чрез `Highlight.js` в уеб изглед (WebView).
* **Управление на данни:** Лесно копиране, споделяне и изтриване на съхранени снипети.

## Технически стек
* **Framework:** .NET MAUI
* **Език:** C#
* **База данни:** SQLite-net-pcl
* **UI/Rendering:** XAML + WebView (за синтактично оцветяване)
* **API Интеграция:** HttpClient (за комуникация с AI услуга - Gemini)

## Настройка на средата

### Предпоставки
* Инсталиран **.NET 8 SDK**.
* **Visual Studio 2022/2023** с инсталиран "Mobile development with .NET" (MAUI).
* Активна интернет връзка.

### Стъпки за стартиране
1.  **Клониране:**
    ```bash
    git clone [https://github.com/yourusername/code-hub.git](https://github.com/yourusername/code-hub.git)
    cd code-hub/Mobile
    ```
2.  **API конфигурация:**
    * Отворете `Services/AiService.cs`.
    * Заменете `YOUR_API_KEY_HERE` с Вашия валиден API ключ.
3.  **Изграждане:**
    * Отворете проекта във Visual Studio.
    * Възстановете NuGet пакетите.
    * Стартирайте проекта чрез бутона "Run" на желан емулатор или физическо устройство.

## Как да използвате приложението
- MainPage: преглед на последни снипети и създаване на нови.
- Create Snippet: попълнете `TITLE`, изберете `LANGUAGE`, използвайте `AI PROMPT` за генериране на код или пък поставете Ваш код в полето.
- Snippet Details: преглед на форматиран и оцветен код; бутон `Explain Code` извиква AI и показва форматирано обяснение.

## Структура на проекта

| Папка | Описание |
| :--- | :--- |
| `Models/` | Дефиниции на обектите (`Snippet.cs`, `CodeResult.cs`). |

## Забележки относно AI интеграцията
Приложението разчита на чист текстов отговор от AI модела. За най-добри резултати, системният промпт трябва да инструктира модела да:
* Връща **само чист код** (без Markdown форматиране или backticks).
* Избягва обяснителни текстове при заявки за генериране на код.
