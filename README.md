# Code Hub (MAUI) - Snippet Manager

## Описание
Code Hub е мобилно приложение, разработено с .NET MAUI (.NET 8), което позволява създаване, преглед и управление на кодови снипети. Приложението интегрира AI модел (през външен API) за автоматично генериране и обяснение на код.

## Характеристики
- Създаване и съхранение на снипети (заглавие, език, код).
- Интегриран AI за генериране на код и обяснения.
- Преглед на форматиран код с подсветка на синтаксис.
- Копиране и споделяне на снипети.
- Мобилен UI, съобразен с тъмна тема и консистентен дизайн.

## Изисквания
- .NET 8 SDK
- Visual Studio 2022/2023 с .NET MAUI workload
- Активен интернет (за AI API и CDN за подсветка на синтаксис)

## Настройка и стартиране
1. Клонирайте репозитория:

   git clone https://github.com/yourusername/your-repo.git
   cd your-repo/Mobile

2. Конфигурирайте API ключа за AI:
- Отворете `Mobile/Services/AiService.cs` и заменете `YOUR_API_KEY_HERE` с вашия ключ, или

3. Възстановете пакетите и билднете проекта във Visual Studio.
4. Стартирайте приложението на желан емулатор/устройство.

## Как да използвате приложението
- MainPage: преглед на последни снипети и създаване на нови.
- Create Snippet: попълнете `TITLE`, изберете `LANGUAGE`, използвайте `AI PROMPT` за генериране на код или пък поставете Ваш код в полето.
- Snippet Details: преглед на форматиран и оцветен код; бутон `Explain Code` извиква AI и показва форматирано обяснение.

## Детайли за ИИ интеграцията
- Файл: `Mobile/Services/AiService.cs`.
- Модел/endpoint: конфигурируеми чрез `Model` и `url` променливите.
- Вход: `prompt` стринг, който може да съдържа инструкции за генериране или обяснение на код. За генерирането на код се включва и език за програмиране, който може да бъде избран от drowdown менюто.
- Формат на отговора: приложението очаква стринг, съдържащ кода.
- Съвети за подобряване на качеството на отговора:
- Ясен prompt с инструкция "Return ONLY plain text".
- Ограничете допълнителни форматирания (без Markdown, без backticks).

## Структура на проекта (основно)
- `Mobile/` - MAUI мобилно приложение
- `Services/` - `AiService`, `DatabaseService`
- `Models/` - `Snippet`, `CodeResult`, `LanguageOptions`
- `Resources/` - стилове и цветове
- `Pages/` - `MainPage.xaml`, `CreateSnippetPage.xaml`, `SnippetDetailsPage.xaml`
